# 嘉立创 PCB 艺术板

面向**二次元 / 图案装饰板**的嘉立创 PCB 工具链。目标用户是没学过电子的玩家：
给一张图 → AI 分层与落板 → 导出 Gerber → 领券下单。

**不是功能板工具**：不涉及原理图、BOM、布线、贴片。

## 安装后你得到什么

### 工具（模型可调用）

| 工具 | 作用 |
|---|---|
| `jlc_validate_constraints` | 校验设计是否满足嘉立创工艺约束：线宽/线距、钻孔、丝印、板边距、沉金面积、免费券规格、彩色丝印六项强约束 |
| `jlc_build_artwork` | **一条命令跑完整流水线**：源图 → 分色 → 矢量化平滑 → 生成 EDA 脚本 + 成品效果图 |

`jlc_build_artwork` 会产出异形板（板框贴合图形剪影）+ 可选挂孔。

### Skill

`jlc-art-pcb` —— 领域知识：分支决策树、八阶段门控、分层方法、工艺阈值、EDA 落板陷阱。

## 两条分支

| | 分支 A：OSP 露铜 | 分支 B：沉金 + 彩色丝印 |
|---|---|---|
| 成本 | 免费（每月 2 张券） | 付费 |
| 视觉 | 铜色 + 板底色 | 全彩 |
| 适合 | 线稿、剪影、单色徽记 | 二次元角色、多彩插画 |
| 硬约束 | — | 仅 2/4 层、白阻焊、沉金、1oz 铜、1U" 金厚、板面无标志 |

**选错分支整块板要重做**，所以 Skill 强制在 P0 定分支。

## 用法

装好后直接说：

> 我想把这张图做成 8×8 cm 的 PCB 挂件，要金色的，能免费用券吗？

模型会加载 Skill，按八阶段推进，调用 `jlc_build_artwork` 生成产物，
再用 `jlc_validate_constraints` 校验。

产物目录结构：

```
<你的工作区>/art-pcb/<项目名>/
├── source.png     原始图
├── final.png      成品效果图（哑黑+金 等）
├── write.js       写入 EDA 的脚本
├── project/       EDA 工程
└── order.md       下单清单（照着选就不会选错）
```

## 环境要求

- **落板需要嘉立创 EDA 专业版 ≥ 4.1.60 桌面版**（自带 `lceda-pro` CLI）。
  在线版不支持 CLI，只能用「运行脚本」手工粘贴 `write.js`。
- **流水线需要 Python 3 + numpy + Pillow**。
  找不到 Python 时可配置插件项 `pythonPath`，或设环境变量 `JLC_PYTHON`。

## 它不做的事

- 不自动下单（嘉立创的下单页需要人工确认与付款）
- 不臆造彩色丝印的线宽/字高（官方没有公开数据，只能靠打样标定）
- 不改你的电脑配置、不删你的工程

## 已知限制

- 目前是**单面板**（顶层）。背面镜像生成尚未实现。
- **彩色丝印的 `Fabrication_Colorful*` 四个文件尚未生成**，
  所以彩印分支还只能手工在 EDA 里操作。
- 分色阈值目前是按示例图标定的，换风格差异大的图需要重新调。
