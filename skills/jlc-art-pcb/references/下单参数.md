# 下单参数

给不懂 EDA 的用户用的**下单决策表**。照着选就不会错，也不会多花钱。

## 新手默认配置（直接照抄）

面向：纯装饰艺术板，无元件，尽量少花钱

| 下单字段 | 选什么 | 为什么 |
|---|---|---|
| 板材类别 | **FR-4** | 唯一支持沉金。铝基/铜基不能沉金 |
| 层数 | **2 层** | 最便宜 |
| 板厚 | **1.6 mm** | 免费沉金券只认 1.6mm |
| 外层铜厚 | **1 oz** | 2oz 加价且线宽要求变粗 |
| 阻焊颜色 | **哑黑**（金线好看）/ 任意（OSP） | 白阻焊会强制黑字 |
| 字符颜色 | 白（哑黑阻焊）/ 黑（白阻焊，系统自动） | 同色不能配 |
| 焊盘喷镀 | **沉金 ENIG**（要金色）/ **OSP**（不要金色） | 决定用哪种券 |
| 金厚 | **1 U"** | 2U" 更贵 |
| 最小孔径 | **0.3 mm（免费档）** | 更小会加收小孔径费 |
| 阻焊覆盖 | **过孔盖油** | 装饰板无功能孔 |
| 出货方式 | **单片出货** | 免费券强制单片 |
| **品质赔付** | **按标准合同常规处理** | ⚠️ 默认/高价档会多收 10 元，艺术板无元件可以是纯浪费 |
| **线路测试** | **AOI全测+飞针抽测** | ⚠️ 默认"全测"是收费项 |
| 交期 | **正常交期** | 5–30pcs 常规工艺 48h 本来就免费 |
| 数量 | **5 片** | 免费券固定 5 片 |
| SMT / 钢网 | **都不选** | 装饰板用不到，勾了还会触发额外约束 |
| 发票 | 不开票 / 个人普票 | 开票 +8%~12% |
| 快递 | 京东/中通/EMS | 免费单已停顺丰包邮 |

**一句话**：
> FR-4 / 2层 / 1.6mm / 1oz / 单片 / 不加急 / 5片 / 标准赔付 / 飞针抽测

## 两种券怎么选（这决定造型风格）

| | **OSP 券** | **沉金券** |
|---|---|---|
| 门槛 | EDA 专用券**零门槛**可领 | EDA 专用券**零门槛**可领 |
| 每月 | 2 张（与其它券共享额度） | 2 张总额，沉金**每月仅 1 次** |
| 层数 | **1–6 层** | **2–4 层** |
| 板厚 | 0.8–1.6mm | **仅 1.6mm** |
| 面积限制 | **无**（整板 OSP） | 沉金面积 **≤20%** |
| 视觉 | 铜色（偏红）+ 板底色 | **金色** + 板底色 |

**关键结论：OSP 更宽松，但只有铜色；沉金能出金色，但面积卡 20%。**

→ **风格与券的匹配**：

| 造型风格 | 该用哪种券 | 原因 |
|---|---|---|
| `solid` 实心剪影 | **OSP** | 大面积铺铜，OSP 无面积限制 |
| `tritone` 三色调 | **沉金** | 金线+白丝印，占比 ≈17% 在 20% 内 |
| `lineart` 线稿 | **沉金** | 线稿面积小，天然 ≤20% |
| `halftone` 半调 | **沉金** | 网点面积可控 |

**OSP 下 `--max-gold` 可以放宽到 0.7~0.9**（此时"金"其实是露铜）；
沉金下必须 ≤0.20。

**注意**：OSP 分支里图案的对比来自「露铜 vs 阻焊覆盖」，
如果整板 100% 露铜，图案就没对比了 —— 要留出阻焊区域做暗部。

## 免费券规则（28 条失效条件里最关键的）

| # | 条件 | 后果 |
|---|---|---|
| 1 | 尺寸 > **10×10cm** | 券失效 |
| 2 | 尺寸 < **1cm** | 券失效 |
| 3 | **拼板出货** | 券失效（只支持单片） |
| 4 | 数量 ≠ 5 片 | 券失效 |
| 7 | 板厚不在 **0.8–1.6mm** | 券失效 |
| 8 | 沉金券 + 板厚 ≠ **1.6mm** | 券失效 |
| 9 | 沉金券 + 沉金面积 > **20%** | 券失效 |
| 12 | 最小孔 < **0.3mm** | 券失效 |
| 14 | 外层铜厚 ≠ 1oz | 券失效 |
| 17 | 「EDA 专用券」+ 非嘉立创EDA原生设计 | 券失效 |
| 21 | 券过期（领取起 **30 天**） | 券失效 |

**每月额度**：2 张（沉金券每月另限 1 次）。

## 沉金计费（两个阈值不矛盾）

| 场景 | 阈值 | 后果 |
|---|---|---|
| 免费沉金券 | 面积 ≤ **20%** | 超出 → 不免费 |
| 付费订单 | 面积 ≤ **30%** | 超出 → 仅超出部分加收 |

- 面积口径：**顶底两面沉金焊盘面积之和 ÷ 板两面面积**
- 基础价：1U" 140 元/㎡；2U" 240 元/㎡

## 彩色丝印（付费，六项强约束）

| 约束 | 值 |
|---|---|
| 层数 | 仅 **2 或 4 层** |
| 阻焊 | **必须白色** |
| 表面处理 | **必须沉金** |
| 外层铜 | **必须 1 oz** |
| 金厚 | **必须 1 U"** |
| 板面标志 | **不能有**（加标志收 10 元） |

- 需**专门的彩色丝印券**，普通沉金券不行
- 不能用黑底 —— 想"哑黑底 + 彩印"做不到
