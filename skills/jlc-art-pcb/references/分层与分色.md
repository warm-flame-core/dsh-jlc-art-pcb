# 分层与分色

> 这一篇解决"把一张图变成制造层"的核心问题。方法与判据部分借鉴自
> [pcb-art-keychain-skill](https://github.com/xxhhwtxx/pcb-art-keychain-skill)（经作者授权），
> 已按本项目场景重写。

## 一、先理解物理：PCB 只有四种材料

从上看一块成品板，你看到的颜色只可能来自这四样东西：

| 材料 | 何时可见 | 颜色 |
|---|---|---|
| **铜**（被阻焊盖住） | 阻焊下面 | 深色（接近板底色的暗调） |
| **铜 + 阻焊开窗** | 开窗且下面有铜 | **沉金=金色**；OSP=裸铜色 |
| **丝印墨** | 印在表面 | 白色（阻焊白时黑色） |
| **阻焊（不开窗）** | 大多数区域 | 板底色（绿/黑/白/蓝/黄/红/紫） |
| 彩色丝印（仅分支B） | UV 打印层 | 全彩 |

**关键推论**：
- 想看到金色 → 必须「铜 + 开窗」**两层同时有**，缺一不可。
- 想要"黑色背景 + 金色图案" → 哑黑阻焊 + 图案处开窗露铜沉金。
- 想要"白色线条" → 丝印层。
- **没有灰阶**：PCB 不能表现半透明和渐变。

## 二、分色流程

### 步骤 1：源图预处理

- 确认分辨率：主图短边 **≥ 1000 px**，徽记类 **≥ 800 px**（低于此缩放到实际尺寸必糊）
- 去 JPEG 压缩噪点（会产生小点、细尖角、白区孔洞）
- **不要**直接缩放位图：110 px 的徽记缩到 φ18 mm 必糊

### 步骤 2：确定目标视觉，再反推分层

先问"最终要看到什么"，而不是"这张图有几个颜色"：

| 目标视觉 | 铜层 | 开窗 | 丝印 | 彩印 |
|---|---|---|---|---|
| 金色图案 + 黑底 | 图案 | 图案处 | — | — |
| 白色线稿 + 任意底 | — | — | 图案 | — |
| 金色描边 + 白色字 | 描边 | 描边处 | 字 | — |
| 全彩插画（分支B） | 可留作细线保护 | 视需要 | 文字装饰 | 主图 |
| 铜色剪影（OSP） | 剪影 | 剪影处 | — | — |

### 步骤 3：生成蒙版

每种材料一张**同尺寸二值蒙版**（黑=该层有图形）：

```
masks/
├── copper.png     铜层
├── mask-open.png  阻焊开窗
├── silk.png       丝印
└── color.png      彩印（仅分支B）
```

**判据**（每条都要算数字）：
- 每条蒙版的最小特征尺寸（线宽、点径）
- 每层面积占板面积比
- 露铜面积占比（沉金预算用）

### 步骤 4：细线保护（重要技巧）

细线是最容易丢的。**把同一条路径同时写进三个层**：

```
铜 + 开窗 + 丝印 三层重合
```

效果：丝印偏了有铜线兜底，铜线断了有白线盖住。

参考 MCH2022 的做法：层间重合度做到 66–90%。

## 三、分色陷阱

| 陷阱 | 后果 | 对策 |
|---|---|---|
| 固定阈值分色 | 灰帽整块变金色 / 淡色细线消失 | 按**区域**分别定阈值，或手动圈选 |
| 全局腐蚀/开运算去毛刺 | **抹掉蕾丝、裙褶、睫毛** | 只做**局部**修复，不做全图形态学 |
| 毛刺修复只改金色 | 旧白区留下尖角白洞 | 白区补偿时只在该白组件轮廓内填回 |
| 直接缩位图 | 小徽记糊成一团 / 按线宽过滤碎成点 | 先矢量化再缩放，或重新生成 |
| 彩色 PNG 当全彩 PCB | 根本打不出来 | 必须分色到物理层 |

> **去毛刺的保守默认值不可跨图沿用。** 某张图 0.11 mm 的圆整半径只适用于那张图。
> 换图必须重新标定，别套用坐标。

## 四、半调：表现灰阶的唯一方法

PCB 没有墨量控制，但**可以用点的疏密**模拟明暗：

- 网点间距 = 想要的分辨率
- 点的大小 = 明暗程度
- **判据**：300 mm 外看应是均匀的灰；100 mm 看能数出点

**陷阱**：点的大小必须 ≥ 工艺最小线宽，否则点会消失变成白块。
一般取点径 ≥ 0.2 mm，间距 0.4–0.6 mm。

## 五、双面镜像（最容易翻车）

做双面板时，**背面三层（铜 2 / 丝印 4 / 开窗 6）必须全部镜像生成**，不只是铜层。

只镜像铜层 → **背面整块反字，一眼可见**。

**坑**：EDA 里"数据镜像"、"显示镜像"、"底面观看镜像"是**三个不同环节**，
无条件叠加会造成双重镜像。要验证：导出 Gerber 后用独立工具看背面层。

## 六、文字

- **优先用文本对象**（矢量），不要光栅化成扫描线——尤其拉丁字母和数字。
- 中文/手写体才考虑光栅化（0.06 mm 扫描线）。
- 汉字在 EDA 里可能被画成实心方块（"四"必中），需要换字体或转曲。
- **弧排小字在 φ18 mm 上会把"四"糊成方块**——宁可不放。

## 七、随机化（应对相似度审核）

免费券有相似度审核黑盒，模板化图案可能被拒。**随机性必须可复现**：

```json
{
  "seed": "shenli-ayaka-001",
  "jitter": {
    "cornerRadiusMm": [0.5, 3.0],
    "frameMotif": "from:12",
    "copperTextureAngle": [0, 90],
    "fontFamily": "from:3",
    "edgeMarkAngle": [0, 6.283]
  }
}
```

所有随机值从 `seed` 派生。好处：

1. 被拒时能**精确复现**那一版
2. 能只改一个维度再提交
3. 能证明"不是模板"

**别**用无种子的 `Math.random()` —— 出了问题无法复现。
