# 嘉立创 PCB 艺术板

一块只有画、没有电路的 PCB。难点不在设计软件，而在三件事：

1. **屏幕上是 RGB，板子上只有四种物理材料**：铜（被阻焊盖住）、铜+开窗（沉金/裸铜）、丝印墨、阻焊。
2. **只有 3 个视觉色调**：板底色 / 金色 / 白色。彩色角色有十几个色阶 —— **必须选择如何压缩**。
3. **"能印"不等于"好看"**：丝印 0.15mm / 字高 1.0mm 只是工业下限。

## 铁律

1. **先定分支，再动笔。** 分支决定层数、阻焊色、表面处理。
2. **先跑画布预检，再写 EDA。** 直接写已存在的板会覆盖用户作品。
3. **量，不要估。** 线宽、字高、金色占比都要有实测数字。
4. **低于下限不是"变细"，是"没有"。**

## 第一步：选券（OSP / 沉金）—— 这是硬开关

两者都免费，但**创作约束完全不同**。脚本里对应 `--finish enig|osp`，
它会自动切换面积上限、层数、板厚校验。

| | `--finish osp` | `--finish enig` |
|---|---|---|
| 领券门槛 | EDA 专用券**零门槛** | EDA 专用券**零门槛**，但每月仅 1 次 |
| 层数 | 1–6 层 | 2–4 层 |
| 板厚 | 0.8–1.6mm | **仅 1.6mm** |
| 面积上限 | **无**（脚本默认 85%，防失去对比） | **20%**（脚本自动钳制） |
| 视觉 | 铜色（偏红）+ 板底色 | **金色** + 板底色 |
| 关键风险 | 整板露铜 → 没有对比 → 图案看不清 | 金面积超 20% → 券失效 |

**怎么选**：

- 用户要「**金色**」→ `enig`。这是绝大多数人的预期。
- 用户只要「**图形**」、想省事、或设计是大面积实心 → `osp`。
- **`solid` 风格只能配 `osp`**（它的金面积接近 100%，沉金券必超 20%）。

**OSP 分支的隐藏陷阱**：图案对比来自「露铜 vs 阻焊覆盖」。
如果整板都露铜（>90%），图案会变成一片均匀铜色，等于没有图案。
所以 OSP 下要把 `--gold-pct` 控制在 30 左右，留出阻焊做暗部。

## 第二步：选风格（本插件的核心开关）

PCB 只有 3 个色调，所以"怎么把彩色图压成 3 色"是成败关键。
用 `jlc_art.py styles` 查看全部预设。

| 风格 key | 中文 | 效果 | 适合 | 不适合 |
|---|---|---|---|---|
| `tritone` | 三色调 | 暗部→金、亮部→白、中间→板底 | **大多数彩色插画（默认）** | 明暗很平的图 |
| `lineart` | 线稿 | 只有深色线条做金 | 黑白漫画、清晰描边的图 | 水彩、厚涂 |
| `halftone` | 半调网点 | 线条做金 + 中间调用点阵 | 照片感、渐变多 | 小尺寸板 |
| `solid` | 实心剪影 | 整个人物做金（≈100%） | 挂件、图标 | **想用免费沉金券时** |

**怎么选**：拿不准就用 `tritone`。用户说"线稿/印章感"→ `lineart`；说"要像印刷网点"→ `halftone`；
说"就要个剪影挂件"→ `solid`（但要提醒他这不能走免费沉金）。

脚本会自动把金色占比**钳制到 ≤20%**（免费沉金券要求），并在 `spec.json` 里记录
`goldPct` 与 `goldLimitHits`。

## 第三步：跑流水线

```bash
python tools/jlc_art.py pipeline <源图> <输出目录> \
  --width-mm 60 --style tritone --hole \
  --js <输出>/write.js --png <输出>/final.png
```

会先做适配性分析（`analyze.py`），再分色、裁板、矢量化平滑、生成 EDA 脚本。

**如果分析给出 poor / fair 警告，先把警告转告用户**，不要闷头往下做。

常见不可行的图：
- **没有可分离背景**（满幅构图、无透明通道）→ 板框会是矩形，效果打折
- **边缘很软**（水彩/厚涂、没有描边）→ 分色接近色块拼接
- **主体分辨率 <800px** → 细节丢失

## 第四步：写进 EDA

**先预检画布**：

```
jlc_audit_canvas(sessionId)
```

返回每块 PCB 的图元数与板框状态，并给出 `action`：
- `create_pcb` —— 工程里没板，新建
- `reuse_pcb` —— 有空的板，复用
- `ask_user` —— **已有内容，必须问用户**（覆盖 / 新建 / 放弃）

**然后**（一次 invoke 批量写入，不要逐条调）：

```bash
lceda-pro invoke --session <id> --ext-uuid eda --timeout 300000 --code-file <输出>/write.js
```

**写入时必须遵守的三条**（实测踩过）：
1. 图元只能写在**已打开**的 PCB 文档上，否则报"参数不正确"
2. 任意多边形只能用 `PrimitivePolyline.create(...) → convertToFill()`
   （`PrimitiveFill` 只支持预设形状；`PrimitiveImage` 会归一化缩放）
3. 坐标单位是 **mil**（1mm = 39.3701mm/mil）

## 第五步：导出与下单

```bash
lceda-pro invoke ... --code "const g = await eda.pcb_ManufactureData.getGerberFile();
  await eda.sys_FileSystem.saveFileToFileSystem('<绝对路径>/gerber.zip', g);"
```

- `getGerberFile()` **必须不传参**，传名字会返回空对象
- **绝不能用 `saveFile()`**（会弹原生对话框卡住流程）

**下单参数**：见 `references/下单参数.md`。核心默认值：

```
FR-4 / 2层 / 1.6mm / 1oz / 单片 / 5片 / 不加急
品质赔付 → 按标准合同常规处理     ← 默认选赔付会多收 10 元，艺术板无元件
线路测试 → AOI全测+飞针抽测       ← 默认"全测"是收费项
阻焊色   → 哑黑（沉金）/ 任意（OSP）
```

## 项目产物结构

```
<工作区>/art-pcb/<项目名>/
├── source.png     原始图
├── final.png      成品效果图
├── write.js       写 EDA 的脚本
├── spec.json      尺寸/占比/阈值记录
├── polys.json     多边形数据
└── project/       EDA 工程（.eprj3 目录，可整体搬移）
```

**工程放置**：`createProject` 不能指定路径，所以先创建、再整体搬到
`art-pcb/<项目名>/project/`、用 `lceda-pro open --path` 从新位置打开。
`.eprj3` 内部全是相对路径与 UUID，搬移**不会断链**（已验证）。

## 工艺阈值（要点）

| 项 | 下限 | 装饰建议 |
|---|---|---|
| 线宽 / 线距 | 0.10 mm | 0.20 mm |
| 丝印线宽 | 0.15 mm | 0.22 mm |
| 丝印字高 | 1.00 mm | 1.20 mm |
| 钻孔 | 0.15 mm（非常规） | 0.30 mm（免费券） |
| 板边到铜 | 0.20 mm | 0.30 mm |
| 沉金占比（免费券） | — | ≤20% |

完整表与官方来源：`references/工艺参数.md`。

## 已知限制（不要对用户过度承诺）

| 限制 | 说明 | 应对 |
|---|---|---|
| **水彩/厚涂图天然不适合** | 没有清晰轮廓线、大量渐变，三色调分色后会碎成色块。实测可辨认但观感差 | **提前告诉用户**："这类图做单色板效果有限，建议换有线稿感的素材，或接受风格化效果" |
| 单面板 | 只做顶层，背面空白 | 需要双面的挂件暂不支持 |
| 彩色丝印未实现 | `Fabrication_Colorful*` 四件套未生成 | 彩印分支只能手工在 EDA 里做 |
| 满幅无背景的图 | 板框会是矩形而非异形 | 用抠图工具去背景，或接受矩形板 |
| 主体 <800px | 细节丢失 | 要 ≥1000px 的源图 |

> **判断技巧**：先用 `python tools/analyze.py <图>` 看评级。
> `poor` 就**别急着往下做**，先把限制说给用户，让他决定换图还是接受。

## 常见故障速查

| 症状 | 先查 |
|---|---|
| 打回来没有金色 | 订单是否真选了沉金；露铜是否超 20% |
| 脸/大面积变白或变黑 | 造型风格选错；试 `tritone` 或调 `--style` |
| 图形很碎 | 源图分辨率低（<1000px）或边缘太软 |
| 板框是矩形而非异形 | 源图没有可分离背景（满幅构图） |
| 沉金费用暴涨 | 沉金面积是否超 30%；口径是否算错 |
| 写入报"参数不正确" | PCB 文档是否已打开；用的是不是 Polyline→Fill |
